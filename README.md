# Node.js Demo App - CI/CD Pipeline

## Task 1: Automate Code Deployment Using CI/CD Pipeline

### Objective

The objective of this task is to create a Node.js web application and automate its build, testing, Docker image creation, and Docker Hub deployment using GitHub Actions.

## Tools Used

- Node.js
- npm
- Git
- GitHub

- Docker
- Docker Hub
